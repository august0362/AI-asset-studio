## Brand & Style

This design system synthesizes the warmth of an artisanal coffeehouse workspace with the precision of a high-tier fantasy anime creative studio. Designed specifically for character production pipelines, the aesthetic blends cozy productivity dashboard ergonomics with high-fidelity anime production dashboards.

The emotional resonance is focused, comfortable, and magical: long generative iteration sessions feel grounded rather than sterile. Tactile control surfaces, parchment-like backgrounds, and warm espresso structural frames counterbalance vibrant celestial mana glows and electric status markers.

Visual principles:
- **Artisanal Ergonomics:** Interfaces avoid harsh technical greys in favor of warm latte undertones, steamed milk surface tiers, and roasted espresso structural outlines.
- **Anime Mana Accents:** Vibrant, luminous accents (electric violet, celestia cyan) are deployed strictly for active synthesis states, generation triggers, and high-energy states.
- **Bilingual Typographic Harmony:** Dual support for English and Vietnamese with careful attention to diacritic clearance, tone mark vertical metrics, and geometric proportions.
- **Tactile Utility:** Controls feature subtle dimensional depth, frosted glass backdrops, and soft rounded enclosures that feel inviting over prolonged usage.

## Colors

The palette system draws from roasted coffee nuances, soft botanical tea grounds, and anime-inspired status tokens. The default light environment is grounded in creamy parchment and rich coffee hues:

### Base & Brand Archetypes
- **Primary (`#8D6E63`):** Warm roasted coffee bean. Anchors primary interactions, active tabs, and refined structural headers.
- **Secondary (`#4E342E`):** Deep espresso roast. Provides definitive contrast for key functional calls-to-action, frame titles, and active selection perimeters.
- **Tertiary (`#8B5CF6`):** Electric mana violet. Reserved for AI character generation cycles, model node links, and creative parameter sliders.
- **Neutral Accent (`#795548`):** Muted mocha tone used for secondary metadata, subtle dividers, and neutral badge text.

### Thematic Canvas Roles
- **Latte Canvas (Light Base):** `#F9F6F0` serves as the canvas substrate, with `#FFFDF9` designating elevated work planes and card surfaces.
- **Structural Espressos:** Dividers and structural borders utilize `#D7CCC8` (subtle) and `#BCAAA4` (interactive frames).
- **Sage Mint Substrates:** `#EDF5F0` delivers serene alternative paneling for script, dialog, and voice-acting sidebars.

### Status & Mana Signals
- **Celestia Cyan (`#38BDF8`):** Rigging, cloth-physics simulation, and live vector preview states.
- **Approval Emerald (`#10B981`):** Art director approval sign-offs and production-ready milestones.
- **Warning Amber (`#F59E0B`):** Parameter drift, high VRAM alerts, and uncommitted generation prompts.
- **Danger Ruby (`#EF4444`):** Node compilation failure and seed regeneration errors.

## Typography

Typography prioritizes bilingual clarity across Latin and complex Vietnamese tonal accents. **Plus Jakarta Sans** provides geometric rhythm and modern video-game presentation headers, while **Be Vietnam Pro** supplies robust, native character construction for extensive production prompts, prompt tokens, and multi-line descriptive metadata.

### Typographic Rules:
- **Diacritic Clearance:** Line heights on body copy are set to at least 1.5× the font size to prevent overlapping tone marks (dấu hỏi, dấu ngã, dấu nặng) on stacked Vietnamese strings.
- **Hierarchy Stacking:** Pair Display and Headline sizes with soft parchment letter-spacing (`-0.02em`) to echo high-end game engine interfaces.
- **Metadata Labels:** `label-sm` utilizes an uppercase transformation with `+0.04em` tracking for node categories, pipeline status pills, and character attribute tags.

## Layout & Spacing

The studio operates on a 1440px target desktop viewport using a multi-pane workstation layout:
- **Left Dock (Navigation & Model Presets):** Fixed 280px drawer.
- **Center Canvas (Character Generation & Viewport Node Graph):** Flexible 12-column grid utilizing `1.5rem` (`24px`) gutters.
- **Right Inspector (Attributes, Layer Blend, Prompt Weights):** Fixed 380px panel.

### Spatial Rhythm:
- Density is optimized for complex generative workflows: components nest comfortably with `space-sm` (8px) internal gaps for related controls and `space-md` (16px) separation between parameter clusters.
- Outer canvas margins on desktop adapt dynamically between `margin-desktop` (40px) down to `margin` (24px) when panels collapse.
- Tablet view collapses side docks into overlay side-sheets; mobile reflows the canvas into a stacked single-column inspection view.

## Elevation & Depth

Visual hierarchy abandons clinical cold grey drop-shadows in favor of warm, espresso-tinted ambient diffusion and frosted parchment glassmorphism.

### Depth Stratification:
- **Level 0 (Canvas Base):** Flat `#F9F6F0` parchment.
- **Level 1 (Card & Workspace Containers):** Solid `#FFFDF9` bounded by subtle `1px` borders in `rgba(141, 110, 99, 0.18)` and an ambient shadow: `0 2px 8px -2px rgba(78, 52, 46, 0.05)`.
- **Level 2 (Active Nodes & Hover Cards):** Translucent backdrop blur (`backdrop-filter: blur(12px)`) at `rgba(255, 253, 249, 0.85)` accompanied by an espresso-lift shadow: `0 8px 24px -4px rgba(78, 52, 46, 0.08), 0 2px 6px -1px rgba(78, 52, 46, 0.04)`.
- **Level 3 (Modals, Overlays & Dragged Nodes):** `0 16px 36px -8px rgba(78, 52, 46, 0.14)`, enclosed in a warm accent stroke `rgba(141, 110, 99, 0.35)`.
- **Mana State (AI Generating):** Outer luminous glow applying tertiary violet: `0 0 20px 2px rgba(139, 92, 246, 0.22)`.

## Shapes

With a roundedness level of `2`, the design system maintains friendly, approachable forms without sacrificing the structured data density required for asset management:

- **Base Radius (`0.5rem` / `8px`):** Applied to input fields, buttons, node handles, and inline code badges.
- **Container Radius (`rounded-lg` / `1rem` / `16px`):** Used for character attribute panels, generation canvas frames, and inspector cards.
- **Surface Enclosure Radius (`rounded-xl` / `1.5rem` / `24px`):** Reserved for modal overlays, contextual flyout menus, and main preview viewports.
- **Full Pill (`rounded-full`):** Explicitly restricted to status badges (`DEMO`, `STAGED`, `APPROVED`) and circular icon triggers.

## Components

### Buttons
- **Primary (Brew Action):** Solid `#8D6E63` texturing with `#FFFDF9` text. Hover shifts to `#4E342E` with a subtle `translate-y-[-1px]` physical lift. 8px radius, height 40px, padding `0 1.25rem`.
- **Magic Action (Run Generation / Inpaint):** Gradient base from `#8D6E63` to `#8B5CF6`, displaying electric violet hover blooms.
- **Secondary (Cozy Outlined):** 1px border `#D7CCC8`, surface `#FFFDF9`, text `#4E342E`. Hover reveals `#EDF5F0` background tint.

### Status Pills & Chips
- **Pipeline Stage Badges:** Height 24px, 9999px border radius, padding `0 10px`, font `label-sm`.
  - *Demo Pill:* Soft parchment `#F5EBE6` background, coffee-toned `#8D6E63` text.
  - *Approved:* Translucent emerald `#10B9811A` background, border `#10B98140`, emerald `#059669` text.
  - *Synthesis Running:* Pulsing `#8B5CF626` background, border `#8B5CF6`, violet `#7C3AED` text.

### Character Cards & Asset Tiles
- **Structure:** 16px corner radius, 1px border `rgba(141, 110, 99, 0.15)`, top visual showcase (1:1 or 3:4 aspect ratio), bottom creamy metadata panel.
- **Hover State:** Border transitions to `#8D6E63` with an elevation jump from Level 1 to Level 2.

### Input Fields & Sliders
- **Text Inputs & Prompt Areas:** `#FFFDF9` surface with `#D7CCC8` border. Active focus shifts the border to `#8D6E63` and adds a warm diffused focus ring (`0 0 0 3px rgba(141, 110, 99, 0.12)`).
- **CFG / Denoising Sliders:** Custom espresso track `#D7CCC8` filled with `#8D6E63`, featuring a thumb knob of `#FFFDF9` with an espresso center dot.

### Node Connectors
- **Splines:** Dynamic cubic-bezier links using 2px stroke width. Idle links carry `#BCAAA4`; energized links transition to `#8B5CF6` with subtle dashed dash-array animations.
